المستكشف الأثري — مشروع Android تجريبي

الوظائف:
- تشغيل كاميرا الهاتف والتقاط صور توثيقية.
- تحديد الموقع الجغرافي وعرض الإحداثيات ودقتها.
- فتح الإحداثيات في خرائط Google.
- حفظ نقاط المسح وملاحظاتها محلياً.
- تصدير سجل النقاط بصيغة JSON.

بناء APK:
يُبنى التطبيق تلقائياً عبر GitHub Actions عند تحديث فرع main.
افتح تبويب Actions، ثم افتح عملية Build Android APK، وبعد نجاحها نزّل Artifact باسم ArchaeologicalExplorer-debug-apk.
بعد فك الضغط ستجد app-debug.apk.

تنبيه علمي وقانوني:
الهاتف والكاميرا وGPS لا تكشف الآثار المدفونة. يلزم جهاز متخصص مثل GPR أو أجهزة المسح المغناطيسي/المقاومة الكهربائية، مع تفسير خبير. التطبيق أداة توثيق ميداني فقط، ويجب إجراء أي مسح أو تنقيب وفق التصاريح الرسمية.
